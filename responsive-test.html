Testing Instructions:

  • Desktop (1440px+): All sections should be wide with 3-column layouts
  • Laptop (1024px-1440px): 2-column layouts, navigation inline
  • Tablet (768px-1024px): 2-column or 1-column layouts, navigation wrapping
  • Mobile (480px-768px): Single column, stacked navigation, larger touch targets
  • Small Mobile (360px-480px): Optimized for small screens, adjusted font sizes
  • Very Small (< 360px): Minimal layout, compact spacing

What to Check:

  • ✓ No horizontal scrolling (overflow)
  • ✓ All text is readable (not too small or too large)
  • ✓ Navigation doesn't overlap
  • ✓ Cards and grids stack properly
  • ✓ Forms are easy to fill on mobile
  • ✓ Buttons are easy to tap (44px min on mobile)
  • ✓ Images and content don't overflow containers

How to Test:

  • 🔍 Chrome/Edge: F12 → Toggle Device Toolbar (Ctrl+Shift+M / Cmd+Shift+M)
  • 🔍 Firefox: F12 → Responsive Design Mode (Ctrl+Shift+M / Cmd+Opt+M)
  • 🔍 Safari: Develop → Enter Responsive Design Mode
  • 📱 Test on actual mobile devices if possible
  • 📐 Resize browser window manually
